# CHOIR-23 — Bloquear decisiones artísticas y definir restricciones

- Estado al snapshot: Por hacer.
- Fuente: [CHOIR-23 en Jira](https://rubengarcia0510.atlassian.net/browse/CHOIR-23).

## Objetivo

Permitir que el director marque decisiones artísticas que el optimizador no
debe modificar.

## Criterios de aceptación

- Se puede bloquear la posición de un coreuta.
- Se pueden definir restricciones de proximidad, sección, movilidad o
  visibilidad.
- El optimizador respeta las restricciones bloqueadas.
- Las restricciones son visibles y editables por el director.

# CHOIR-25 — Generar y rankear alternativas de transición

- Estado al snapshot: Por hacer.
- Fuente: [CHOIR-25 en Jira](https://rubengarcia0510.atlassian.net/browse/CHOIR-25).

## Objetivo

A partir de dos formaciones, generar alternativas viables y ordenarlas por
calidad escénica.

## Criterios de aceptación

- Se genera al menos una alternativa cuando existe una solución válida.
- Las alternativas muestran métricas comparables.
- Se priorizan menos movimiento, menos cruces y respeto de restricciones.
- El director puede elegir una alternativa sin perder la formación original.
